## Adding evidence

Add reviewed copies to `evidence/screenshots/`. Redact credentials and unrelated personal information first. Preserve an evidence ID, caption, capture date and timezone with each copy. Label any cropped or redacted image. Keep originals separately.

## Confidence labels

- **Recorded observation:** described in the prior evidence record; original not re-reviewed here.
- **User reported:** a user statement without independent measurement in this documentation.
- **Not verified:** evidence is absent or insufficient.
