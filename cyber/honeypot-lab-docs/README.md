# Honeypot Lab Documentation

Documentation of local honeypot testing and troubleshooting in a Proxmox-based home lab.

Updated: 11 October 2026 (Australia/Melbourne).

## Current status

The existing evidence record documents running OpenCanary and Cowrie containers. Local HTTP, FTP, MySQL and Telnet interactions produced responses and corresponding OpenCanary output. Cowrie interaction and external reachability are not verified.

This repository records completed observations and remaining work. It does not contain test archives, disk images, credentials or archive-generation code.
